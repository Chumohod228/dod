# Телеуправление двумя руками на одной шине

Актуальная запись лидера сохранена в `leader_ranges.json` (ID 7–12, запись
`results/manual_ranges_20261009T111338_775748Z`). Она загружается по умолчанию:

```bash
python3 leader_follower.py --port /dev/ttyACM0 --check-only
python3 leader_follower.py --port /dev/ttyACM0
```

Для этих команд обе руки должны быть подключены к общей шине. Границы лидера
непрерывные, с учётом перехода через ноль; они применяются программно, без изменения
аппаратного нуля лидера. Инструкция ниже описывает повторную запись диапазонов.

`leader_follower.py` читает лидера и управляет фолловером через один USB–TTL адаптер
Waveshare, 1 Мбит/с. Все 12 приводов — STS3215, ID уникальны.

| Лидер | Фолловер |
|---:|---:|
| 7 | 1 |
| 8 | 2 |
| 9 | 3 |
| 10 | 4 |
| 11 | 5 |
| 12 | 6 |

Скрипт передаёт команды движения и включения момента только ID 1–6.
Лидер должен быть свободен для ручного перемещения (момент выключен);
его EEPROM и целевые позиции скрипт не изменяет. Другие программы управления
шиной на время работы должны быть закрыты.

## 1. Записать диапазоны лидера

```bash
cd /home/chumohod/dod
python3 record_ranges.py --port /dev/ttyACM0 \
  --ids 7 8 9 10 11 12 --output results/leader_calibration
```

После сообщения `RECORDING` проведите каждый сустав лидера через весь нужный рабочий
диапазон и завершите запись Ctrl+C. Папка должна быть новой; для повторной записи
задайте другое имя. Регистратор проверяет, что момент выбранных приводов выключен.

```bash
python3 analyze_ranges.py results/leader_calibration
```

Получится `results/leader_calibration/continuous_ranges.json` с непрерывными границами.
Переходы через 4095↔0 учитываются. Для этого между соседними успешными измерениями
сустав должен проходить меньше половины оборота. Изменять аппаратное смещение нуля
лидера для этого скрипта не требуется. Используются поля `minimum` и `maximum`,
а не предложенные центрированные диапазоны из анализатора.

Не применяйте к записи лидера `apply_calibration.py`: текущая процедура предназначена
для фолловера и обновляет его `limits.json`. После любого изменения нуля лидера
нужно заново записать его диапазоны.

## 2. Проверить соединение без движения

```bash
python3 leader_follower.py --port /dev/ttyACM0 \
  --leader-ranges results/leader_calibration/continuous_ranges.json --check-only
```

Проверяются все 12 ID, модель, режим положения, диапазоны фолловера, положение обеих
рук, отсутствие ошибок приводов и выключенный момент лидера. В режиме `--check-only`
отправляются исключительно запросы чтения.

## 3. Включить следование

```bash
python3 leader_follower.py --port /dev/ttyACM0 \
  --leader-ranges results/leader_calibration/continuous_ranges.json
```

После проверок включается управление фолловером. Начальная цель равна его измеренному
положению, далее цель плавно приближается к положению, заданному лидером. Начальные
позы рук могут отличаться. По умолчанию скорость ограничена 600 отсчётами/с, ускорение
задано регистром 50, целевая частота цикла — 50 Гц. Скорость команд дополнительно
ограничивается программно с учётом прошедшего времени.

Преобразование для каждой пары:

```text
t = (положение_лидера - минимум_лидера) / (максимум_лидера - минимум_лидера)
цель_фолловера = минимум_фолловера + t × (максимум_фолловера - минимум_фолловера)
```

Для суставов, вращающихся в противоположную сторону, укажите ID **фолловера**:

```bash
python3 leader_follower.py --port /dev/ttyACM0 \
  --leader-ranges results/leader_calibration/continuous_ranges.json \
  --invert 2 3 --speed 400
```

Для инвертированных пар используется `1-t`. По умолчанию инверсии нет. Диапазоны
фолловера берутся из актуального `limits.json` рядом со скриптом; их можно явно задать
через `--follower-limits`. Отображается доля хода каждого сустава, поэтому при разных
размахах обеих рук равенство физических углов не гарантируется.

Остальные параметры: `--duration 60` (по умолчанию до Ctrl+C), `--hz 50`,
`--acceleration 50`, `--deadband 2`, `--timeout 0.03`, `--max-read-age 0.2`.
При джиттере цели менее 2 отсчётов новая команда не посылается. Небольшой выход лидера
за границы до 16 отсчётов обрезается до края диапазона; больший выход останавливает
следование. Скачок больше 1024 отсчётов за цикл также останавливает его
(`--max-leader-step` настраивается).

## Остановка и журнал

Недостижение цели и статус перегрузки фолловера `0x20` не завершают следование.
Если цель не достигнута, скрипт повторяет её каждые 0,5 с (`--retry-interval`, минимум 0,1 с).
При перегрузке повторные команды данному приводу ограничены этим периодом даже при
движении лидера; остальные суставы продолжают следовать. В журнал попадает статус,
а в консоль — предупреждение и ошибка положения `err` в отсчётах. Перезапуск после
перегрузки тоже допускается. Регистры ограничения тока, момента и аппаратной защиты
не изменяются: достижимое усилие определяется приводом и его настройками.

Ctrl+C, таймаут, слишком старые данные и остальные ошибки (включая питание,
перегрев и сверхток, в том числе одновременно с перегрузкой) завершают следование.
Ошибки лидера по-прежнему считаются критическими.
Скрипт пытается прочитать свежие положения фолловера и отправить цели удержания.
Момент фолловера остаётся включённым. Если шина недоступна, программная остановка
не гарантируется: приводы могут дойти до последних целей.

`results/teleop_<время_UTC>/` содержит `samples.csv` (положения, ток и напряжение обеих
рук), `commands.csv` (цели фолловера), `peaks.csv` и `summary.json`. Раз в секунду
выводятся пары «положение лидера → цель фолловера», напряжение и ток фолловера.
Фактическая частота зависит от времени обмена со всеми 12 приводами.
